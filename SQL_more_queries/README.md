# SQL - More queries

This project covers MySQL users and privileges, constraints, subqueries and joins.

## Files
| File | Description |
|------|-------------|
| 0-privileges.sql | Lists all privileges of the MySQL users user_0d_1 and user_0d_2 |
| 1-create_user.sql | Creates the user user_0d_1 with all privileges |
| 2-create_read_user.sql | Creates the database hbtn_0d_2 and the user user_0d_2 with SELECT only |
| 3-force_name.sql | Creates the table force_name (name can not be null) |
| 4-never_empty.sql | Creates the table id_not_null (id default 1) |
| 5-unique_id.sql | Creates the table unique_id (id default 1 and unique) |
| 6-states.sql | Creates the database hbtn_0d_usa and the table states |
| 7-cities.sql | Creates the table cities with a foreign key to states |
| 8-cities_of_california_subquery.sql | Lists the cities of California using a subquery |
| 9-cities_by_state_join.sql | Lists all cities with their state using a join |
| 10-genre_id_by_show.sql | Lists shows that have at least one genre |
| 11-genre_id_all_shows.sql | Lists all shows with their genre id (NULL if none) |
| 12-no_genre.sql | Lists shows without a genre |
| 13-count_shows_by_genre.sql | Lists genres with the number of shows linked |
| 14-my_genres.sql | Lists the genres of the show Dexter |
| 15-comedy_only.sql | Lists all Comedy shows |
| 16-shows_by_genre.sql | Lists all shows with all their genres |
