# SQL - Introduction

This project introduces MySQL and basic SQL queries.

## Files
| File | Description |
|------|-------------|
| 0-list_databases.sql | Lists all databases of the MySQL server |
| 1-create_database_if_missing.sql | Creates the database hbtn_0c_0 if it does not exist |
| 2-remove_database.sql | Deletes the database hbtn_0c_0 if it exists |
| 3-list_tables.sql | Lists all the tables of a database in the MySQL server |
| 4-first_table.sql | Creates a table called first_table in the current database |
| 6-list_values.sql | Lists all rows of the table first_table |
| 5-full_table.sql | Prints the full description of the table first_table |
| 7-insert_value.sql | Inserts a new row (89, Best School) in the table first_table |
| 8-count_89.sql | Displays the number of records with id = 89 in the table first_table |
| 9-full_creation.sql | Creates the table second_table and adds multiple rows |
| 10-top_score.sql | Lists all records of second_table ordered by score (top first) |
| 11-best_score.sql | Lists all records of second_table with a score >= 10, ordered by score (top first) |
