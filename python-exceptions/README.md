# Python - Exceptions

This project teaches how to handle errors in Python using try, except and finally, and how to raise exceptions.

## Requirements
- Python 3 (Ubuntu 20.04 LTS, python3 3.8.5)
- Code follows pycodestyle
- All files are executable and start with `#!/usr/bin/python3`

## Files
- `0-safe_print_list.py`: prints x elements of a list safely
- `1-safe_print_integer.py`: prints an integer safely
- `2-safe_print_list_integers.py`: prints only the integers of a list
- `3-safe_print_division.py`: divides two integers safely
- `4-list_division.py`: divides two lists element by element
